# Data Sources & Provenance Registry (DAT-06)

This document tracks all dataset sources, licenses, and collection protocols for OvaScan AI.

## 1. Primary Tabular Dataset
- **Name**: Polycystic Ovary Syndrome (PCOS) Dataset
- **Curator**: Prasoon Kottarathil (Kaggle)
- **Cohort Size**: 541 Patients (44 columns)
- **Origin**: Clinical centers in Kerala, India
- **License**: CC BY-SA 4.0
- **Limitations**: Single-source hospital cohort; lacks Total/Free Testosterone by LC-MS/MS, Fasting Insulin, and oral glucose tolerance tests (OGTT).

## 2. Ultrasound Image Cohort
- **Name**: PCOS Detection using Ultrasound Images
- **Curator**: Anagha Choudhari (Kaggle)
- **Format**: 2D Transvaginal Ultrasound Scans
- **License**: Open Academic Research

## 3. External Validation Image Cohort
- **Name**: PCOS-XAI Ultrasound Dataset
- **Curator**: Ibadeus (Kaggle)
- **Purpose**: Independent evaluation of out-of-distribution ultrasound morphology.
